About the Help Wanted Dub Archive

This fan-made project aims to document and catalog all official international dubs and broadcasts of the pilot episode of SpongeBob SquarePants ("Help Wanted" / 1999).

  • Data Verification: Information is sourced from community preservation efforts and verified databases like DubDB.
  • Multiple Dubs: Languages with redubs or alternate network releases feature expandable version sub-rows.
  • Video Availability: Streams are provided where legitimate fan embeds exist. Versions without confirmed links remain cataloged for historical completeness.
